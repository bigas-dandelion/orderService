# Order Service

Демонстрационный микросервис на Go, предназначенный для получения данных о заказах из очереди сообщений (Kafka), сохранения их в PostgreSQL и предоставления через HTTP API с кэшированием в памяти.

## Описание

Сервис реализует следующие функции:

- Подписка на топик Kafka и обработка входящих сообщений с данными о заказах.
- Валидация и сохранение данных в PostgreSQL.
- Кэширование последних заказов в памяти для ускорения ответов на запросы.
- HTTP-эндпоинт для получения данных заказа по `order_uid`.
- Простой веб-интерфейс для ввода ID заказа и отображения информации.

Сервис устойчив к ошибкам: некорректные сообщения логируются и игнорируются, а данные не теряются благодаря использованию транзакций и механизма подтверждения сообщений в Kafka.

---

## Архитектура

- **Kafka** — брокер сообщений, источник данных о заказах.
- **orderService** — основной микросервис на Go.
- **PostgreSQL** — постоянное хранилище данных.
- **In-memory cache** — `LRU` для быстрого доступа к данным.
- **Web UI** — статическая HTML-страница с JavaScript для взаимодействия с API.

## Быстрый старт

### Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/bigas-dandelion/orderService.git
   cd orderService
   ```

2. Запустите контейнеры (Kafka, PostgreSQL):
   ```bash
   make up
   ```

3. Дождитесь выполнения контейнера KafakaInit и отправьте сообщение в топик:
   ```bash
   make produce
   ```

4. Сделайте миграции к базе данных (накат):
   ```bash
   make migrate-up
   ```

5. Запустите основной сервис:
   ```bash
   make run
   ```

6. Откройте веб-интерфейс и в поле ввода вставьте полученный id-заказа:
   ```
   http://localhost:8082
   ```

7. Остановка основного сервиса:
   ```bash
   Ctrl+C
   ```

8. Остановка контейнеров:
   ```bash
   make down
   ```

   Откат миграций из бд:
   ```bash
   migrate-down
   ```

### Доступные команды (`make help`)

```text
up        — запустить Kafka и PostgreSQL через Docker Compose
down      — остановить и удалить контейнеры
run       — запустить основной сервис (cons)
produce   — отправить тестовое сообщение в Kafka (prod)
migrate-up — накат миграций в бд
migrate-down — откат миграций из бд
help      — список дотсупных команд
```

## HTTP API

### Получить заказ по ID

```http
GET /order/{order_uid}
```

**Пример:**
```bash
curl http://localhost:8082/order/123e4567-e89b-12d3-a456-426614174000
```

**Ответ (200 OK):**
```json
{
  "order_uid": "123e4567-e89b-12d3-a456-426614174000",
  "track_number": "WBILMTESTTRACK",
  "entry": "WBIL",
  "delivery": { ... },
  "payment": { ... },
  "items": [ ... ],
  "locale": "en",
  "internal_signature": "",
  "customer_id": "test",
  "delivery_service": "meest",
  "shardkey": "9",
  "sm_id": 99,
  "date_created": "2023-01-01T12:00:00Z",
  "oof_shard": "1"
}
```

## 📎 Модель данных

Структура заказа включает вложенные объекты:
- `delivery` — данные доставки
- `payment` — данные оплаты
- `items` — список товаров
